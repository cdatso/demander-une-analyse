Demander une analyse

Proposez un film. Le service vérifie d'abord s'il est déjà analysé sur le site ; sinon, il qualifie votre demande et l'ajoute à une file d'attente publique.

Votre demande apparaîtra dans une file publique — le titre, le réalisateur, l'année et la qualification. Votre adresse électronique, si vous la donnez, n'y apparaîtra pas : elle est conservée mais n'est pas publiée. Aucune analyse n'est écrite automatiquement : la décision d'analyser un film, et l'analyse elle-même, restent humaines.
